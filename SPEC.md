# ASTRA FUSION QUANT - System Specifications

This project implements the Astra Fusion Quant engine as specified in the master blueprint.

## Milestones Achieved
- **M0**: Core repository and config structures.
- **M1**: Data validation, session handling, HTF processing, core indicators (ATR, RSI, ER).
- **M2**: Market structure, Zone lifecycle (FVG), regime detection.
- **M3**: Family scoring, ensemble consensus, risk modeling, hard gates.
- **M5**: Local execution simulator in Python.
- **M6/M7**: Walk-forward validation framework, stress testing, holdout unsealing.
- **M8**: Production Pine Script implementations (Indicator + Strategy).

**Note**: `pine/astra_indicator.pine` is the primary executable deliverable for TradingView.
